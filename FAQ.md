# FAQ

## Kan ik niet gewoon zelf een website bouwen met AI?

- **Strategie:** waarom staat welke knop waar, en waarom werkt die aanpak voor jouw type klant?
- **SEO:** zonder juiste structuur en techniek vindt Google je site niet
- **Onderhoud:** wat als er een bug is, een pakket verandert, of je site trager wordt?
- **Persoonlijk advies:** iemand die meedenkt over jouw bedrijf, niet enkel code aflevert

Bij Timmers Design krijg je geen generieke AI-output, maar een site die specifiek gebouwd is om bezoekers om te zetten in klanten — met persoonlijk contact en nazorg inbegrepen.

Kort gezegd: AI kan een site bouwen. Ik bouw een site die werkt.
